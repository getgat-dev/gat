Pull fetches missing content, then updates working files to match the current lock.
[History selectors](/concepts/history-selection) prefetch additional objects; they do not
restore an older revision. Check out that revision with Git first.
Use {{command:fetch}} to download without changing working files.

See [how sync plans changes](/concepts/how-gat-works#how-sync-decides-what-to-change)
and [resolving local conflicts](/concepts/automatic-sync#local-changes-and-conflicts).
